# v4 — User-composed hybrid

**Origin:** User feedback round 1 — picked "mix" with explicit guidance: "v2 hero (centered) + add v1's Get notified form; v3 categories with restyle; remaining sections from v1, optimize with v2 style polish."

**Hierarchy:** Centered editorial hero with conversion ask up front (best of both v1's CTA velocity and v2's brand expression), then editorial roster categories with refined hierarchy color underlines, then v1's product/trust/business sections re-spaced with v2's whitespace discipline.

**Sections (in order):**

1. **Sticky nav** — minimal (v2 pattern): logo + wordmark + "Get notified at launch" quiet link with brass-gold underline.
2. **Centered editorial hero (v2 structure + v1 form)** — gold ornament eyebrow "Launching in Atlanta · 2026", AIRA tree-of-life logo at 140px, Cormorant headline "A directory of Atlanta's Indian community, *curated with care*", italic tagline "Roots & *Reach*", **email form inline below** (input + "Notify me at launch" button), fine-print disclaimer.
3. **About — editorial 2-col (no card)** — gold ornament + eyebrow "Why we built this" + serif headline "The opposite of an algorithm and a pile of *scraped data*", then 2-column body: left has drop-cap paragraph; right has 2 supporting paragraphs in muted tone. No boxed card frame — pure editorial typography.
4. **Categories — v3 editorial roster, refined** — section header "From *dosa* to *doctors*", then a 7-row roster with: roman numeral in italic gold serif (left), Cormorant category name with tier-color underline (center), italic Cormorant subtitle, gold › arrow (right). Subtle hover state lifts the row + nudges the arrow right.
5. **Phone showcase (v1 two-phone tilted)** — Home + Listings screens side-by-side, tilted -7° / +7°, large drop shadows. Copy on right: "Built for the way you *actually* look for things" + 3 bullet points with serif primary-green chevrons.
6. **Trust 3-col (v1 structure, v2 ornamentation)** — gold ornament + eyebrow + "Three things that *don't change*" headline, then 3 cols: brass-gold-bordered icon circles + Cormorant subhead + muted body. Curated by hand / Verified by community / Operated by Nisarga.
7. **Business panel (v1 olive section, more breathable)** — full-bleed olive bg with green paper texture, 2-col grid: copy + 4 checkmark perks + cream CTA button on left; listing card preview + italic caption on right.
8. **Footer (v1 4-col)** — brand block + For users / For businesses / Legal columns + bottom bar with copyright + "Operated by Nisarga Group LLC ✦".

**Refinements vs the parent variants:**

- **Hero email form is centered** (not left-aligned like v1) — matches the centered hero composition.
- **Categories rows have hover affordance** — background tint + arrow translates right. Pure brand-press the static v3 roster didn't have.
- **About section dropped the right-column card** from v1 — too SaaS-y. Replaced with flowing 2-col editorial body.
- **More vertical breathing room** between sections (120px vs v1's 96px) — matches v2's slower rhythm.
- **Trust icons gain a brass-gold border ring** — small touch but ties them into the ornamental gold accent used elsewhere.

**Why this should land:**
- Conversion path is short (form visible in hero) without sacrificing brand depth (centered editorial composition reads premium).
- Categories no longer look like a SaaS feature grid — they read like a magazine's "Sections" page.
- Whitespace + serif emphasis throughout signal "curated with care" before you read the headline.

**Risks to watch:**
- The drop-cap in About could clash with the hero on small screens — verify mobile.
- Hover states on category rows won't be visible on mobile — make sure tap targets still feel clear.
- 7-row categories list might feel long; could collapse to 4-5 visible + "+ more" if scroll fatigue tests show it.
