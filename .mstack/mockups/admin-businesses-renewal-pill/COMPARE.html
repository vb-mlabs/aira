Renewal urgency pill — variant compare

Four explorations of how to surface renewal urgency directly on /admin/businesses without merging the dedicated /admin/renewals call queue. Same 7 sample rows in every variant so the differences are apples-to-apples.

v1 — Inline soft-escalation pill Calmest · no row treatment
v2 — Stacked caption + overdue left-border Scannable from afar
v3 — Single combined badge Tightest · loses raw status
v4 — Pill + jump-to-call action Most actionable · row tint
Each variant is also viewable standalone: v1/index.html, v2/index.html, v3/index.html, v4/index.html. See BRIEF.md for the framing and each variant's NOTES.md for the trade-offs.
