# v1 — Compact list (classifieds density)

**Pattern:** Single-column rows on a cream card, divided by hairlines. Title,
one-line excerpt, name + date, "X helping" pill, and a small "I can help"
button per row. ~6 rows per screen on desktop.

**When this wins:**
- Volume grows (50+ active requests) and people want to scan fast
- "Marketplace where I might browse for things I didn't know I needed" framing
- Mobile-first: the row collapses naturally to one item per screen

**Tradeoffs:**
- Each request feels less weighted; emotional pull of someone asking for help
  is muted by the density
- Excerpt truncated to one line — no preview of detail
- "I can help" is a small target, easy to miss

**Detail page:** same density carries into the respondent list (rows with
avatar + name + message paragraph), which means non-author and author views
share the same visual rhythm.
