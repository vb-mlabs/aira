# v3 — Featured hero + dense secondary feed

**Pattern:** One post promoted to a dark-olive featured hero card at the top
(same green texture as the AIRA sidebar), then a 2-column grid of compact
mini-cards below for everything else. Single "Ask the community" CTA in the
header bar.

**Featured-selection rules** (to confirm later):
- Newest post by default, OR
- Highest interest count in the last 7 days, OR
- Manual admin-pinned

**When this wins:**
- Want a visual focal point on the page — "this is what's happening right now"
- Mixes density (one hero + 6+ mini-cards visible without scrolling on desktop)
- Featured pattern echoes the listings tier system (Sponsored top), so users
  already understand it

**Tradeoffs:**
- Decision burden: who picks the featured? Needs business rules (or admin
  toil) the other variants don't
- Mini-cards lose the per-row "Helping" badge — only the count icon survives
- 2-column grid is less mobile-natural (becomes 1 column anyway, defeating
  density advantage on the most-used breakpoint)

**Detail page:** the post becomes the featured-hero treatment full-screen, then
the respondents render as a 3-column card grid below. Visually striking but
breaks the "one screen, one post" calm — the grid pulls attention back to the
"what should I do next?" layer instead of letting the author read messages
slowly.
