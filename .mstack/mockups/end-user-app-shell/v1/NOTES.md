# V1 — Grid-Led

**Concept:** The category grid is the primary visual element on Home — 7 large tiles arranged in a 3-2-2 masonry-style grid. Below the grid sits a "Featured" section with 6 business cards. Navigation is a standard top bar.

**What makes V1 distinct:**
- Categories feel like destinations — each tile is large enough to show the category icon and name clearly
- Featured section sits below the fold, rewarding scroll
- On mobile, the grid collapses to 2 columns; featured scrolls as a horizontal carousel
- Clean, portal-like feel — most familiar pattern for a directory app

**Best for:** Users who know what category they want immediately; first-time users scanning the full offering.
