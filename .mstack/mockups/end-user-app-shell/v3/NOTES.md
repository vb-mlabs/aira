# V3 — List-Led

**Concept:** A horizontal scrolling row of category pills sits just below the nav. Below that, businesses appear immediately in a full-width vertical list (not cards) with a compact row design. The emphasis is on scanning many businesses fast.

**What makes V3 distinct:**
- Zero extra clicks to see businesses — home page = listings page
- Category switching is a single tap on a pill, content updates below
- Business rows are compact: logo thumbnail + name + tier dot + verified badge + chevron
- Featured businesses are marked with a star/tier badge inline rather than a separate section
- On mobile: same layout, pills scroll horizontally, list fills the screen

**Best for:** Goal-oriented users who arrive knowing they want to browse; efficient for power users; feels more like a modern app than a web directory.
