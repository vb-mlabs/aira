## Failure modes hit during the run (all fixed; documented in runbook)

In order of appearance:

1. `eas.json` `autoIncrement` schema: must be boolean at the profile
   level (the string form is per-platform only). → `ae5f010`.
2. `eas init` non-fatal error on dynamic configs: project IS created,
   error message misleading; we manually paste the suggested
   `extra.eas.projectId` block. → `4de2289`.
3. `eas update:configure` same dynamic-config pattern. → `ebb2c0a`.
4. EACCES rmdir on `.cache/dotslash/.../React Native DevTools-linux-x64`
   from Replit `/tmp/runner/*` perms. Fix: nuke `.cache/` at source +
   `DOTSLASH_CACHE=$HOME/.dotslash-cache` env override.
5. `Unknown system error -122` copying `.local/share/pnpm/store/`.
   Fix: workspace-root `.easignore` excluding `.local/`, `.npm/`,
   `.config/`, `.replit`, etc. → `c470135`.
6. iOS "Install dependencies" + Android "Prebuild" failures because
   workspace `.easignore` excluded `tooling/` (`@aira/tsconfig`
   unresolvable) and `.npmrc` (Metro needs `node-linker=hoisted`).
   → `5d2f00b` + `3b06392`.
7. `sharp@0.34.5` couldn't install on EAS's iOS macOS runner;
   `node-gyp` source-build fallback failed. Fix: moved to
   `optionalDependencies` on `apps/web/package.json`. → `4111b08`.
8. `whatwg-fetch` peer dep not found by Metro because pnpm's
   isolated layout hides it from the resolver. Fix: explicit direct
   dep + `.npmrc` copy at project root. → `b60d599`.
9. iOS `distribution: "internal"` (preview profile) triggered UDID
   registration loop. Fix: skipped preview, went straight to
   production. (See decision-log entry 2026-06-23.)
10. EAS submit failed because `eas.json` lacked a `submit` profile.
    Fix: added `submit.production.ios.ascAppId = "6783242682"` +
    `submit.production.android.track = "internal"`. → `6e6d4a0`.
11. Google Play Android Developer API not enabled in the Cloud
    project. Fix: enabled at
    `console.developers.google.com/apis/api/androidpublisher.googleapis.com/overview?project=810026001638`.
